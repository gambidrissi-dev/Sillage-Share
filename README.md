# Sillage

Navigateur web léger sur WebKit, onglets mis en veille.

**[Télécharger la dernière version](https://github.com/gambidrissi-dev/Sillage-Share/releases/latest/download/Sillage.zip)** · macOS 26 ou plus récent

Ce dépôt ne contient pas de code : il distribue Sillage. L'app se met à jour toute seule
par [Sparkle](https://sparkle-project.org) depuis [`appcast.xml`](appcast.xml), et chaque archive est signée (EdDSA).
